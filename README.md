# checkers-lite

极简英式跳棋（English draughts）引擎，纯 Python 标准库，无第三方依赖。

## 玩法

- 8×8 棋盘，只在深色格走子；你执红（●/♛）先行，AI 执黑（○/♕）
- **有吃必吃**、连跳；兵走到对方底线升王（♛/♕，可前后走/吃）
- 跳入底线即升王，本回合停止（美式规则）；多条吃子路线可任选
- 对方无子或无合法走法（被困死）即获胜

## 运行

```bash
python3 -m checkers_lite            # 人机对战（红方）
python3 -m checkers_lite --auto     # AI 对 AI 无头演示（默认 4 局）
python3 -m checkers_lite --auto --games 8 --depth 3 --seed 42
```

走法输入示例：`c3 d4`（一步）、`c3 e5 g7`（连跳），`q` 退出。

## 设计取舍

- AI 为带 alpha-beta 剪枝的浅层搜索（默认深度 2），评估函数只有子力+推进加成，没有开局库和残局库
- `--auto` 设 160 半回合上限防无限对局，超时判和棋

## 局限

- AI 较弱：深度 2 经常错过 3 步以上的连跳陷阱；深度 3+ 明显变慢
- 无开局/残局优化，无吃子数最多强制规则（美式规则任选其一）
- 命令行回合制，无图形界面
